### 🚀 Featured Projects

#### 💬 [Private PDF Chatbot (RAG)](https://github.com/toobasyeda18-oss/RAG-Private-Pdf-Chatbot)
A fully local chatbot that answers questions from your PDFs with page-level citations. Documents never leave your machine.
* Page-aware chunking, vector search with Qdrant, and local LLMs through Ollama
* Query rewriting, streaming answers, and source citations (page number and match percentage)
* Built with a FastAPI backend and Streamlit interface, containerized with Docker Compose

`Python` `FastAPI` `Streamlit` `Qdrant` `Ollama` `Docker`

#### 🚘 [License Plate Recognition System](https://github.com/toobasyeda18-oss/License_plate_recg)
Detects license plates in uploaded videos and reads their text.
* YOLOv11 detection trained and evaluated in Jupyter on UK road footage, paired with EasyOCR text extraction
* Implements confidence scoring and CSV export for verification
* Results stored in MySQL with timestamps and a Flask web app interface for uploading videos

`Python` `Flask` `OpenCV` `YOLOv11` `EasyOCR` `MySQL`

#### 📋 [Whiteboard Scanner to Digital Notes](https://github.com/toobasyeda18-oss/White-board-scanner)
Detects and straightens a whiteboard in a photo, enhances it, and extracts the text.
* Built a computer vision tool in Python using OpenCV and NumPy to detect whiteboard boundaries and apply perspective correction
* Integrated RapidOCR and a Streamlit interface with WER/CER evaluation to extract clean, editable digital text from skewed photos

`Python` `OpenCV` `RapidOCR` `Streamlit`

#### 🛡️ IoTShield: Intelligent Intrusion Detection System for IoT Networks
Published research paper (*IJSRD*, Vol. 13, Issue 2, 2025) • O Grade
* Developed an intrusion detection system using SVM and ANN to classify IoT network traffic
* Used the TON_IoT dataset with Synthetic Data Vault for data augmentation, improving accuracy and reducing false positives

`Python` `Machine Learning` `SVM` `ANN` `Cyber Security`
